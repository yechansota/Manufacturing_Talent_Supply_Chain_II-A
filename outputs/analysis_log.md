# Analysis log — II-A

II-A (*Where Each Floor Job's Successors Come From*) is exploratory and descriptive; it is **not** pre-registered.
The project began as one repository with a pre-registered core (now II-B, *From the Production Line to Maintenance*,
frozen 2026-10-18). Under DL-36 the analyses reported here moved to this repository.

- **DL-n** rows are verbatim copies of II-B's deviation log, with their original IDs, dates and timestamps: every entry
  whose analysis runs here or that this repository's code or outputs cite. They are not edited here; II-B keeps the
  complete log, including entries for analyses that run only there.
- **AL-n** rows are entries made in this repository after the split. Each is logged before the analysis it describes is
  run, or says so when it is not.

Types and columns follow II-B's log: **clarification** = an implementation reading that the plan leaves open;
**addition** = an extra analysis that does not replace an earlier one; **change** = a modification.
